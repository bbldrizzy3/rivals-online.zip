# Rivals Arena (online)

First-person arena shooter with lobbies, room codes, 4-gun loadouts and arena voting.

## Run locally
    npm install
    npm start
Open http://localhost:3000 in two browser tabs/computers on your network.

## Deploy on Render (free)
1. Push this folder to a GitHub repo.
2. On render.com: New > Web Service > connect the repo.
3. Build command: `npm install`  Start command: `npm start`
4. Open the URL Render gives you and share it with friends. Use a room code to play together.

## Controls
WASD move, mouse look (click once to capture), Space shoot, Up Arrow jump, 1-4 / wheel / Q swap guns, R reload, Left/Right arrows also turn, right-click zoom (sniper).
